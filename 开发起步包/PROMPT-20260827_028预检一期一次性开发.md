交付一个**可运行、测试全绿、零生产依赖**的归档前预检服务原型：

### A. 独立服务 `prearchive_service/`（仓库根一级目录，Python 3.11）

1. **目录纪律（028 §2 隔离边界，违反即返工）**：
   - 全部代码在 `prearchive_service/` 内；**禁止 `import app.*`**（含 app.config/app.database）；不修改仓库任何现有文件（仅允许新增 + 修改 `开发起步包/01_统一修改记录.md`）；
   - 依赖只写 `prearchive_service/requirements.txt`（cx_Oracle/psycopg2-binary/pyodbc/SQLAlchemy/fastapi/uvicorn/pydantic/cryptography/pytest 等自定，pyodbc 只出现在这里）；
   - 自带 `prearchive_service/README.md`（运行/测试/部署说明草案）与 `prearchive_service/config.example.json`（**不含任何真实口令**，字段用占位符）。
2. **配置模块**：独立 JSON 配置加载 + Fernet 加密凭据（独立实现，不共享主服务 SECRET_KEY）；键：轮询间隔/四源连接(占位)/推送(HMAC)/规则文件路径/日志。
3. **触发轮询**：`pat_visit.finished_date_time` 增量轮询循环（可配间隔默认 5 分钟、防重入锁、断点续跑水位持久化）；**检查键 (patient_id, visit_id, finished_date_time)，完成时间更新即重检**（028 A1 复检语义）。
4. **四源采集器**：JHEMR(pat_visit/v_blws)、HIS(T_ITF_HIS)、手麻(T_ITF_SM)、LIS(dbo.vw_hisinter_T_ITF_Lis)；**字段按 028 §1 F1/F3 v2 修正版**（LIS=FDESCNUM 无 FDESC；HIS REPORTNAME 是数字编码）；每个采集器有接口抽象 + **fixture 假源实现**（本地测试用，数据字段名与真实一致）。
5. **规则引擎**：四类判定器 missing_doc/time_limit/empty_field/duplicate + DSL 加载校验（**028 §3.2 v2 完整字段**：enabled/version/dept_codes/exempt/min_hours_after_event/require_source_ready/exclude_vocab/template_field；'无' 不在空项黑名单）；带 `rules/example_rules.json` 示例规则 ≥6 条（手术核查表缺失/术前术后文书族/入院记录24h时限/首页过敏空项[条件规则，源不可用时整族跳过]/诊断重复/检验报告族），每条标注"对应 t_mark_item FID 待质控科签字版回填"。
6. **结果存储**：SQLAlchemy 独立模型 `PrearchiveResult`（检查键三列联合、每检一行、current 标记、问题 JSON、推送状态、规则版本）；建表 DDL 脚本放 `sql/` **不自动执行**；单测用 SQLite 内存库。
7. **企微推送模块**：HMAC-SHA256 独立实现（协议参考 `app/services/relay_alert_service.py` 的签名构造，**只读参考不 import**）+ **契约测试向量**：构造固定 secret/payload/timestamp 断言签名值，向量样例同时留档 `tests/contract_vectors.json`（供未来与 relay 双实现比对）；接收人解析：完成医生优先/管床兜底（接口抽象，映射函数可注入 mock）；单患者合并一条、同一 result_id 双通道去重字段。
8. **健康端点 + 自监控心跳**（R13）：服务心跳文件/接口，停跳可被外部探测。

### B. 外挂提醒助手骨架 `prearchive_service/reminder_agent/`（C#，首选 4.1 外挂方案）

- 独立 WinForms 托盘程序骨架：读配置 → 定时轮询预检服务 API（工号+科室带鉴权头）→ 置顶弹窗（owner=EMR 主窗口句柄，窗口标题前缀可配容错）→ 已知晓/去整改；
- **fail-open 铁律**：全域 try-catch 自包裹，服务不可达/超时/异常数据一律静默降级为托盘图标状态，**任何异常不得影响任何其他程序**；
- 线程编组合规（STA/Invoke），UI 找不到目标窗口时退化为普通置顶窗；
- 用本机 `C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe` 可编译（提供 `build.bat`）；无法编译也不阻塞——代码交付+编译说明即可；
- **不写任何 AppDomainManager/IL 注入代码**（那是 4.2/4.3，不在本次范围）。
