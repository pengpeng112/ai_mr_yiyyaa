## 3. 按分析 AI 的类型给它文件的方式

| 分析 AI 类型 | 给法 |
|---|---|
| 本机 CLI AI（ZCode/Codex/Claude Code 等，能读文件） | 直接把本说明给它 + 第 2 层目录路径，它自行 Read；ZCode 还可用 `ReadSessionContext` 按 INDEX.md 里的 `sess_*` ID 定点取上下文 |
| 云端/公网 AI（网页版 ChatGPT/GLM/Kimi 等，需上传文件） | **必须先跑第 2 层带 `--redact` 的导出**，再从导出目录挑选文件上传；单文件过大（>500KB 的 03 号）可拆段上传；未打码导出一律不上传 |
| 第三方桌面工具（AnythingLLM/Kotaemon 等，能索引本地目录） | 指向第 2 层打码导出目录建索引即可；不要索引 `review/` 其余子目录（门禁日志等噪声大） |

> 注意：`review/` 整个目录**不入 git**（.gitignore 第 102 行），换机器/换人时文件要线下拷贝，git clone 拿不到。
