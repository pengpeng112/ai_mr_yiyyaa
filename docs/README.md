# 文档入口

请先阅读 [`INDEX.md`](INDEX.md)。它是本项目唯一的文档导航、状态清单和归档入口。

- `ACTIVE/`：当前待执行计划。
- `reference/`：现役协议、基线和防回归资料。
- `archive/`：历史方案、提示词、界面设计和测试报告；仅用于追溯，不作为当前实现依据。
- `remediation/`：整改证据、备份 JSON 与回退说明（含 2026-08-17 三轮降级备份）。
- `attachments/`：截图与导出附件（含患者隐私，禁止提交 git 与外发）。
- `skills/`、`sql/`：文档技能与 SQL 资产。
- `3一致性核查正式版-质控门禁影子V2.yml`：唯一 Dify 待复核工作流（2026-08-19 起收敛）。
