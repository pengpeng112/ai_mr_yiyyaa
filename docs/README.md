# 文档入口

请先阅读 [`INDEX.md`](INDEX.md)。它是本项目唯一的文档导航、状态清单和归档入口。

多工具/模型开发请按 [启动导航](../开发起步包/README.md) 接手，方法和模板见 [119协作指南](reference/119_MULTI_AI_COLLABORATION_GUIDE.md)。INDEX按用途提供导航，任务板只维护会话负责者和恢复点。

- `ACTIVE/`：现役计划及尚保留原路径的交付/历史证据；是否待执行以 INDEX 状态和最新交付为准。
- `reference/`：现役协议、基线和防回归资料。
- `archive/`：历史方案、提示词、界面设计和测试报告；仅用于追溯，不作为当前实现依据。

- `remediation/`：整改证据、备份 JSON 与回退说明（含 2026-08-17 三轮降级备份）。
