## 1. 就绪包 v2 修订（第一批插入前完成；仅以下三项内容变更，其余不动）

- **V1 科室门控**：第一批插入版 SETTING_SQL 的门控用"占位不命中"字面量——`AND DEPT_DISCHARGE_FROM='PILOT-PENDING'`（任何患者都不满足，即使被误启用也零弹窗）。第二批激活前 UPDATE 为正式双门控：
  ```sql
  AND p.DEPT_DISCHARGE_FROM=':PILOT_DEPT' AND '{5}'=':PILOT_DEPT'
  ```
  （`{5}`=点击者当前科室码占位符，C# Format 代入后与试点科室码字面量比较；两条件同时成立才命中。注意 string.Format 契约：SQL 中字面量花括号必须写 `{{` `}}`，本门控不含字面量花括号。）
  **预检**：试点科真实账号登录，核对界面当前科室码（CurrentUser.CurrentDeptCode）与该科 `dept_discharge_from` 是否同码值——若护理单元码与出院科室码非同一套，此门控会整科不弹，须换门控字段后再激活。
- **V2 R2 文案**：`【质控提醒】未检出出院记录类文书，提交病历完成前请核查病历完整性。`（删"到院记录"笔误）。
- **V3 R3 算法**：`TRUNC(SYSDATE) - TRUNC(p.DISCHARGE_DATE_TIME) > :DAYS`（双 trunc 自然日差；`:DAYS` 第一批占位 3，第二批按质控科制度值定稿并同步改 TIPMESSGE 中的数字）。
