# 质控结果准确性抽检执行计划

## 任务目标

从生产数据库抽取近 30 天、严重度为高（high）的质控日志，每个审计类型随机抽取 20 条（共 100 条），逐条对比"推送日志原文（mr_text）"与"AI 质控结论（ai_result）"，判断 AI 的判定是否准确、合理，是否存在误报、漏报或证据引用错误。

## 执行步骤

### 第一步：抽样

对每个审计类型，从 Oracle 随机抽取 20 条高危记录。

抽样 SQL 模板：

```sql
SELECT * FROM (
  SELECT ID, PATIENT_ID, PATIENT_NAME, PUSH_TIME, QUERY_DATE,
         AUDIT_TYPE_CODE, AUDIT_RUN_MODE, RISK_SCORE, SEVERITY
  FROM MED_PUSH_LOG
  WHERE SEVERITY = 'high'
    AND STATUS = 'success'
    AND AUDIT_TYPE_CODE = :type_code
    AND PUSH_TIME >= SYSDATE - 30
  ORDER BY DBMS_RANDOM.VALUE
) WHERE ROWNUM <= 20
```

5 个类型各抽 20 条，共 100 条。

### 第二步：逐条拉取完整数据

对每条记录，查询 MR_TEXT 和 AI_RESULT：

```sql
SELECT ID, MR_TEXT, AI_RESULT, REQUEST_JSON
FROM MED_PUSH_LOG WHERE ID = :id
```

建议将每条记录的 mr_text 和 ai_result 写到本地文件：
- `/tmp/audit_review/{type}/{id}_mr.txt`
- `/tmp/audit_review/{type}/{id}_ai.txt`

### 第三步：逐条对比分析

对每条记录，执行以下分析：

#### 3.1 输入数据核查

1. **时间匹配核查**：mr_text 中的病历记录（入院/病程/护理/检验/检查）是否按规则同日匹配？是否存在跨天错误配对？
2. **数据完整性**：mr_text 中是否有关键记录缺失（如入院记录为空、病程为空、护理为空）？
3. **异常标记核查**：检验/检查的异常标记是否正确？正常结果是否被误标为异常？
4. **EMR 时间 vs 临床时间**：病程记录的 EMR 创建时间与临床内容时间是否一致？是否因补录导致日期错位？

#### 3.2 AI 结论核查

1. **结论是否正确**：AI 标记的"不一致"或"矛盾"在 mr_text 原文中是否真实存在？
2. **证据引用是否准确**：AI 引用的证据（如"肌张力高 vs 肌张力低"）在原文中是否能找到？引用的文字是否与原文一致？
3. **严重度是否合理**：AI 给出的风险分和严重度（high/medium/low）是否与问题的实际严重程度匹配？是否存在小问题标高危（过度报警）或大问题标低危（漏报）？
4. **维度覆盖是否完整**：AI 是否只检查了部分维度而遗漏了其他明显问题？
5. **是否有幻觉**：AI 是否描述了 mr_text 中不存在的矛盾或问题？

#### 3.3 判定结论

对每条记录给出以下判定之一：

| 判定 | 含义 |
|---|---|
| ✅ **准确** | AI 结论与原文证据吻合，严重度合理 |
| ⚠️ **部分准确** | 主要结论正确但细节有误（如证据引用不精确、遗漏次要问题） |
| ❌ **误报** | AI 标记了不一致但原文中实际不存在该问题 |
| 🔍 **漏报** | AI 遗漏了 mr_text 中明显的问题 |
| ⏰ **时间匹配错误** | mr_text 本身存在跨天错误配对，导致 AI 基于错误输入做判断 |
| 📝 **数据问题** | mr_text 数据缺失或异常（非 AI 责任） |

## 各审计类型的重点核查维度

### admission_vs_first_progress（入院 vs 首次病程）

重点核查：
- 入院记录和首次病程是否是**同一天**的同一患者
- 查体描述是否存在矛盾（如肌张力高/低、瞳孔描述、肌力描述）
- 初步诊断是否与入院记录的病情描述一致
- AI 引用的矛盾原文是否能在 mr_text 中精确定位
- 是否存在因为 EMR 补录延迟（病程创建时间晚于入院数天）而导致的误判

### jyjc_vs_bcnursing（检验检查 vs 病程护理）

重点核查：
- mr_text 中"逐日关联"的结构是否合理——是否有不该出现在同一天的数据被强制归组
- 顶部"检验检查"/"病程"/"护理"三节是否正确反映了同日匹配结果
- AI 声称"病程未关注异常检验"——核查当天是否真的没有病程记录
- AI 声称"异常检验"——核查原始检验结果是否真的异常（对比参考范围）
- 是否存在正常结果被当异常分析的情况
- 出院终末模式下，逐日列表是否包含大量无关天数的噪声数据

### progress_vs_nursing（病程 vs 护理）

重点核查：
- 病程记录中的医嘱与护理记录中的执行是否吻合
- 病情描述（如体温、意识状态）在病程和护理中是否一致
- AI 标记的矛盾是否真实存在于两份记录之间
- 是否存在护理记录先于病程（时间倒挂）的不合理配对

### syssvsscbc（医嘱 vs 病程及护理）

重点核查：
- 医嘱内容是否在病程记录中有对应分析
- 医嘱内容是否在护理记录中有对应执行
- AI 标记的"未执行"医嘱——核查当天护理记录中是否真的缺失
- 是否存在长期医嘱/停止医嘱被误判为"未执行"

### surgery_chain（手术链）

重点核查：
- 手术首页、术前讨论、手术记录、术后病程是否完整
- 手术日期在各个记录中是否一致
- AI 标记的"缺失环节"是否真的缺失
- 是否存在因数据源查询问题导致的假性缺失

## 执行注意事项

1. **不要修改任何数据**：只做查询和分析，不执行 UPDATE/DELETE/INSERT
2. **不要修改配置**：不保存配置、不启停调度、不推送
3. **大字段处理**：MR_TEXT 和 AI_RESULT 是 CLOB，用 cx_Oracle 读取时需 `.read()` 或直接转 str
4. **编码问题**：Oracle 返回的中文可能需要处理编码，建议在容器内执行 Python 脚本
5. **输出控制**：每条记录的分析可以详细，但汇总要简洁
6. **抽样代表性**：使用 `DBMS_RANDOM.VALUE` 或 `ORDER BY DBMS_RANDOM.RANDOM` 确保随机性
7. **时间范围**：`SYSDATE - 30` 即近 30 天，不需要精确到小时

## 推荐执行方式

在容器内创建一个 Python 脚本完成抽样+拉取+结构化输出，然后将结果写到 `/tmp/audit_review/` 目录，最后下载到本地分析。

```python
# 容器内执行脚本模板
import cx_Oracle, json, os

conn = cx_Oracle.connect("jhemr", os.environ["MED_AUDIT_ORACLE_PASSWORD"], "10.10.8.216:1521/orcl")
cur = conn.cursor()

TYPES = [
    "admission_vs_first_progress",
    "jyjc_vs_bcnursing",
    "progress_vs_nursing",
    "syssvsscbc",
    "surgery_chain",
]

os.makedirs("/tmp/audit_review", exist_ok=True)

for t in TYPES:
    # 抽样
    cur.execute("""
        SELECT * FROM (
          SELECT ID, PATIENT_ID, PATIENT_NAME, PUSH_TIME, QUERY_DATE,
                 AUDIT_TYPE_CODE, AUDIT_RUN_MODE, RISK_SCORE, SEVERITY
          FROM MED_PUSH_LOG
          WHERE SEVERITY = 'high' AND STATUS = 'success'
            AND AUDIT_TYPE_CODE = :tc AND PUSH_TIME >= SYSDATE - 30
          ORDER BY DBMS_RANDOM.VALUE
        ) WHERE ROWNUM <= 20
    """, tc=t)
    samples = cur.fetchall()
    cols = [d[0] for d in cur.description]

    dirname = f"/tmp/audit_review/{t}"
    os.makedirs(dirname, exist_ok=True)

    for row in samples:
        d = dict(zip(cols, row))
        rid = d["ID"]
        # 拉取大字段
        cur.execute("SELECT MR_TEXT, AI_RESULT FROM MED_PUSH_LOG WHERE ID = :id", id=rid)
        r2 = cur.fetchone()
        def reads(v):
            if v is None: return ""
            if hasattr(v, "read"): return v.read()
            return str(v)
        mr, ai = reads(r2[0]), reads(r2[1])
        with open(f"{dirname}/{rid}_mr.txt", "w") as f: f.write(mr)
        with open(f"{dirname}/{rid}_ai.txt", "w") as f: f.write(ai)
        print(f"{t} ID={rid} mr={len(mr)} ai={len(ai)}")

    # 保存抽样清单
    with open(f"{dirname}/_sample_list.json", "w") as f:
        json.dump([dict(zip(cols, row)) for row in samples], f, ensure_ascii=False, indent=2, default=str)

conn.close()
print("DONE")
```

执行后将 `/tmp/audit_review/` 打包下载，逐条分析。
