# 推送日志页面与菜单栏联合优化方案

参考截图：推送日志页面
参考预览：`推送日志页面优化预览.html`
改造原则：**不改接口、不改字段、不改路由、不改权限，只优化菜单栏、筛选区、统计卡片、表格密度和操作体验。**

---

## 1. 当前截图主要问题

### 1.1 左侧菜单问题

当前菜单仍存在明显重复和层级混乱：

```text
质控闭环
  患者质控
质控闭环
  患者质控
  前置机告警
质控闭环
  患者质控
  前置机告警
  质控反馈
...
```

问题：

1. 重复分组太多。
2. 当前所在菜单虽然高亮，但用户很难判断属于哪个业务模块。
3. 菜单滚动条很长，查找效率低。
4. 子菜单文字偏小，状态和待办数量没有聚合展示。

---

### 1.2 推送日志页面问题

截图中推送日志功能完整，但页面比较“表格后台化”：

1. 顶部统计数据混在文字中，不够直观。
2. 筛选条件横向堆积，视觉压力大。
3. “已推送未复核 / 检查检验数据为空 / 医生未查看”等重要筛选项不够突出。
4. 表格列多，行高和字体层级不够清楚。
5. 操作按钮“详情 / 更多”太弱，和数据列混在一起。
6. 底部分页显示太长，`3244` 页直接暴露，视觉不友好。
7. 当前页没有明确说明：这是“日志明细”还是“问题处理台”。

---

## 2. 菜单栏改造方案

### 2.1 推荐菜单结构

将左侧菜单压缩为 6 个一级分组：

```text
工作台
├── 首页总览

质控闭环
├── 患者闭环
├── 前置机告警
├── 推送日志
├── 整改跟踪

推送调度
├── 手动推送
├── 定时任务
├── 接收人配置

数据分析
├── 统计报表
├── 科室风险
├── 维度分析

系统配置
├── 系统配置
├── 规则配置
├── 角色权限

运维工具
├── 系统健康
├── 接口文档
```

### 2.2 当前页面菜单定位

当前页面为：

```text
质控闭环 / 推送日志
```

因此：

```text
质控闭环 分组默认展开
推送日志 高亮
其他分组默认折叠或保持上次状态
```

### 2.3 菜单 badge

建议增加真实 badge：

```text
患者闭环：医生未查看数，例如 31
前置机告警：失败数，例如 22
推送日志：失败日志数，例如 702
定时任务：ON/OFF
系统健康：UP/DOWN
```

没有真实数据时不要显示假数字。

## 3. 推送日志页面改造方案

## 3.1 页面标题区

当前标题只有“推送日志”，建议加一句说明，降低用户理解成本。

```text
推送日志
查看患者质控推送、跳过、失败和未复核记录，支持筛选、导出和批量处理。
```

右侧操作：

```text
刷新
导出 CSV
批量重推
```

注意：

```text
批量重推必须受权限控制
批量删除建议弱化或放入更多操作，避免误删
```

---

## 3.2 顶部 Tab

建议保留并扩展为：

```text
推送日志
数据统计
失败分析
批量任务
```

如果后端暂时没有“失败分析 / 批量任务”，可先只展示：

```text
推送日志
数据统计
```

不要增加无功能入口。

---

## 3.3 统计卡片

将当前文字统计改成 5 张小卡片：

```text
总记录     64876
跳过       14586
失败       702
未复核     10584
数据为空   3933
```

颜色：

| 指标 | 颜色 |
|---|---|
| 总记录 | 蓝色 |
| 跳过 | 橙色 |
| 失败 | 红色 |
| 未复核 | 红/橙 |
| 数据为空 | 灰色 |

卡片高度建议：

```text
86px
```

---

## 3.4 筛选区

### 3.4.1 核心筛选

保留一行核心筛选：

```text
状态
告警级别
在院科室
出院科室
患者姓名
患者ID
检查类型
查询
```

### 3.4.2 高级筛选折叠

以下字段建议放入高级筛选：

```text
开始日期
结束日期
是否隐藏已重试
重试次数
失败原因类型
严重度
```

如果全部堆在一行，页面会显得拥挤。

### 3.4.3 快捷筛选 chip

把常用筛选做成 chip：

```text
隐藏已重试
已推送未复核 14584
检查检验数据为空 3933
医生未查看 10584
可重试失败 702
```

点击 chip 直接设置筛选条件。

---

## 3.5 表格区

### 3.5.1 表格标题

表格上方增加标题：

```text
日志明细
```

右侧增加：

```text
列设置
高级筛选
密度：紧凑
```

### 3.5.2 表格列建议

当前列基本可保留：

```text
选择
推送时间
患者ID
姓名
在院科室
出院科室
检查类型
状态
严重度
重试
失败/跳过原因
操作
```

### 3.5.3 表格样式

建议：

```text
表头 sticky
行高 46px
字体 12-13px
状态使用 pill 标签
检查类型使用灰色 pill
操作按钮收敛
```

### 3.5.4 详情/更多操作

建议：

```text
详情：主操作
更多：下拉菜单
```

更多里放：

```text
重推
查看原始记录
复制患者ID
查看失败原因
```

---

## 3.6 分页区

当前页码显示：

```text
1 2 3 4 5 6 ... 3244
```

建议保留，但视觉弱化：

```text
Total 64876 · 每页 20 条
‹ 1 2 3 4 5 … 3244 ›
```

同时支持：

```text
跳转页码
每页条数
```

但不要把跳转输入框做得过抢眼。

## 4. 实施步骤

### Commit 1：菜单去重和当前页定位

```text
fix: deduplicate sidebar menu and highlight push log route
```

内容：

1. 合并重复质控闭环分组。
2. 推送日志归入“质控闭环”。
3. 保留原路由。
4. 当前页面显示为“质控闭环 / 推送日志”。

---

### Commit 2：推送日志顶部区域优化

```text
fix: polish push log header and summary cards
```

内容：

1. 标题区增加说明。
2. 操作按钮统一到右侧。
3. 文字统计改为卡片统计。
4. 不改统计接口。

---

### Commit 3：筛选区重构

```text
fix: improve push log filters and quick chips
```

内容：

1. 核心筛选保持一行。
2. 高级筛选折叠。
3. 常用筛选改为 chip。
4. 查询/重置按钮样式统一。

---

### Commit 4：表格密度和操作优化

```text
fix: improve push log table readability
```

内容：

1. 表头 sticky。
2. 行高统一。
3. 状态和严重度改为 pill。
4. 操作按钮统一。
5. 增加列设置入口。

---

### Commit 5：分页和响应式

```text
fix: refine push log pagination and responsive layout
```

内容：

1. 分页视觉弱化。
2. 支持窄屏横向滚动表格。
3. 保证 1366 和 1920 宽度可用。
