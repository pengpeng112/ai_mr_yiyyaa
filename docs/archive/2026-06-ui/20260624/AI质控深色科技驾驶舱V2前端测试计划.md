# AI质控深色科技驾驶舱 V2 前端测试计划

目标：验证本次首页深色科技驾驶舱 V2 改造后，前端各功能是否正常显示、正常跳转、正常操作，且不影响系统其它核心页面。

测试环境：生产服务器 `http://10.10.8.84:8000`

测试范围：前端页面展示、菜单跳转、首页 KPI、图表、刷新、详情打开、筛选、响应式、异常/空状态。

不测试范围：后端统计口径正确性、Dify 工作流准确性、Oracle 数据真实性、业务规则医学正确性。

---

## 1. 测试前准备

### 1.1 浏览器要求

建议至少测试以下浏览器：

1. Chrome 最新版
2. Edge 最新版

### 1.2 基础准备

1. 打开 `http://10.10.8.84:8000`
2. 使用有效账号登录系统
3. 打开浏览器开发者工具 Console
4. 测试过程中观察是否出现红色 JS 错误
5. 打开 Network 面板，确认关键接口请求状态码是否为 200 或被前端容错处理

### 1.3 测试记录格式

每个用例按以下格式记录：

```text
用例编号：
测试结果：通过 / 不通过 / 阻塞
实际表现：
问题截图：如有
Console 错误：如有
Network 异常：如有
备注：
```
