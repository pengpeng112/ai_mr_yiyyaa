## 检查维度（每个页面逐项检查）

| 维度 | 说明 |
|---|---|
| **加载** | 是否白屏、JS 报错、模板 404、未渲染 `{{ }}` |
| **布局-桌面** | 1366x768 下无横向溢出，卡片对齐，表格不撑破 |
| **布局-平板** | 768x1024 下可读，弹窗不超屏 |
| **布局-手机** | 390x844 下单列或可横向滚动，菜单可打开 |
| **交互** | 刷新/查询/重置/详情/复制 等按钮可点击且有反馈 |
| **空状态** | 无数据时是否可读，不纯白块 |
| **数据展示** | null/空值显示为 `--`，长文本不撑破，JSON 可复制 |
| **视觉一致性** | 红=失败/高危，橙=警告，绿=成功，蓝=运行，灰=禁用；表格密度统一；深色首页不污染浅色页 |

## 问题记录格式

```
问题编号：FE-REG-XXX
页面：xxx
环境：生产/本地 + Chrome + 分辨率
严重度：高/中/低
现象：
  一句话描述
复现步骤：
  1. xxx
  2. yyy
预期结果：
  应该怎样
实际结果：
  实际怎样
Console 错误：
  如有粘贴
Network 错误：
  如有粘贴 URL+状态码
疑似涉及文件：
  static/templates/pages/xxx.html 等
建议修复：
  最小修复建议
```

**严重度定义**：
- **高**：白屏、JS 报错、模板 404、主要功能不可用、生产配置误存风险、移动端完全不可用
- **中**：布局明显错位、表格遮挡、详情不可读、按钮/状态不清晰、交互路径受阻
- **低**：间距、颜色、文案、轻微溢出、旧版风格残留
