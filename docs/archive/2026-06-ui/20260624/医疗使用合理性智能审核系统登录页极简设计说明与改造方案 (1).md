# 医疗使用合理性智能审核系统登录页设计说明与前端改造方案

参考设计图：`医疗使用合理性智能审核系统登录页设计稿_极简版.png`
目标仓库：`pengpeng112/ai_mr_yiyyaa`
目标页面：系统登录页
设计方向：**极简、专业、安全、院内业务系统风格**
核心要求：**去掉“医保控费”字样，去掉默认账号密码提示，不影响原有登录功能。**

---

## 1. 设计总目标

本次登录页不再做大篇幅宣传说明，也不展示过多系统能力文案，而是采用“左侧品牌视觉 + 右侧登录表单”的极简结构。

设计目标如下：

1. 登录页看起来像正式院内系统，而不是临时测试页。
2. 页面文字减少，只保留必要信息。
3. 系统名称统一为：`医疗使用合理性智能审核系统`。
4. 医院名称保留：`山东省第二人民医院`。
5. 页面不再出现：`医保控费`。
6. 页面不再出现默认账号、默认密码、测试账号。
7. 保留原有登录功能、登录接口、token/session、跳转逻辑。
8. 兼容桌面端和小屏端。

---

## 7. 右侧表单交互规范

## 7.1 用户名输入框

属性建议：

```html
<input
  id="username"
  name="username"
  type="text"
  placeholder="请输入用户名"
  autocomplete="username"
/>
```

要求：

```text
1. 不默认填入 admin。
2. 不显示默认账号。
3. 支持 Enter 提交。
4. 保留原有 v-model / 表单绑定。
```

---

## 7.2 密码输入框

属性建议：

```html
<input
  id="password"
  name="password"
  type="password"
  placeholder="请输入密码"
  autocomplete="current-password"
/>
```

要求：

```text
1. 不默认填入密码。
2. 不显示明文密码。
3. 不在 localStorage 保存密码。
4. 不在 console 打印密码。
```

---

## 7.3 记住账号

只允许记住用户名。

允许：

```js
localStorage.setItem('remembered_username', username)
```

禁止：

```js
localStorage.setItem('password', password)
localStorage.setItem('remembered_password', password)
```

推荐逻辑：

```js
if (rememberUsername) {
  localStorage.setItem('remembered_username', loginForm.username)
} else {
  localStorage.removeItem('remembered_username')
}
```
