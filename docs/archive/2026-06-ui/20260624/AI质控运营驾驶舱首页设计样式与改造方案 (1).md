

## 2. 当前截图界面主要问题

### 2.1 左侧菜单过长且重复

截图中左侧菜单有大量重复的分组和菜单项，例如多处出现：

```text
质控闭环
患者闭环
前置机告警
```

问题：

1. 菜单视觉噪音很大。
2. 用户难以判断当前所在位置。
3. 左侧滚动很长，占用注意力。
4. 分组和子项层级不够清楚。

---

### 2.2 首页指标区域重复

截图中“日运行指标”出现了两组类似内容。

问题：

1. 用户会误以为是不同数据口径。
2. 实际上容易造成重复展示。
3. 首屏空间被重复卡片占用。

建议：

```text
保留一组“日运行指标”
另一组改为“风险与闭环指标”或删除
```

---

### 2.3 图表区域空白过大

截图中：

```text
近30天时效趋势
风险等级分布
历史维度分布
风险事件流
```

多个图表区域为空白。

问题：

1. 页面看起来像未加载完成。
2. 用户不知道是无数据还是接口异常。
3. 大面积白色卡片降低驾驶舱质感。

建议：

```text
无数据时显示明确空状态
有接口异常时显示异常提示
不建议空白显示
```

---

### 2.4 顶部标题区域层级不够强

当前标题区虽然显示“AI质控运营驾驶舱”，但与下面指标卡没有形成完整驾驶舱头部。

建议做成：

```text
标题 + 说明 + 系统状态 + 更新时间 + 刷新
```

---

### 2.5 卡片样式偏平

当前卡片虽然清爽，但缺少层级、色条、状态提示和卡片用途区分。

建议：

```text
KPI 卡片增加左侧状态色条
主值加大
辅助说明弱化
风险类用红/橙
成功类用绿
运行状态用蓝
```

### 5.3 KPI 卡片

统一样式：

```css
.kpi {
  height: 112px;
  border-radius: 18px;
  background: #fff;
  border: 1px solid #e5edf6;
  padding: 18px;
  box-shadow: 0 10px 28px rgba(15, 23, 42, .06);
  position: relative;
  overflow: hidden;
}

.kpi::before {
  content: "";
  position: absolute;
  inset: 0 auto auto 0;
  width: 4px;
  height: 100%;
  background: var(--tone);
}
```

颜色建议：

| 指标类型 | 颜色 |
|---|---|
| 运行总量 | `#2563eb` |
| 成功 / 自动率 | `#16a34a` |
| 不一致 / 失败 | `#ef4444` |
| 预警 / 未查看 | `#f97316` |

---

### 5.4 图表卡片

图表卡片不要空白。

无数据时显示：

```text
暂无趋势数据
等待今日任务执行后生成
```

接口异常时显示：

```text
数据加载失败，请稍后刷新
```

加载中显示：

```text
骨架屏 / loading
```

不要只留空白。
