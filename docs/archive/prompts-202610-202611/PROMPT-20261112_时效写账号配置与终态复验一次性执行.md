## 三、口令与密钥安全

### 3.1 口令来源

执行 AI 不得把聊天中的明文口令复制到 Shell 命令、Python 字符串、临时脚本、配置明文键、日志、报告、测试或 Git 文件。

口令只能由用户在执行 AI 的运行环境中预置为：

```text

```

执行 AI 只检查该环境变量是否存在，由 Python 在内存中读取并加密，不得打印其值。

- 不得要求用户再次把口令贴到聊天中；

- 可继续不依赖口令的授权复核、门禁和报告工作；

- 不得降低生产密钥校验。

### 3.3 零明文检查

### A2.3 精确列级权限矩阵

```sql
WITH expected(column_name, want_select, want_update) AS (
    VALUES
        ('patient_id',             true,  false),
        ('visit_id',               true,  false),
        ('monitor_code',           true,  false),
        ('apply_date_time',        true,  false),
        ('apply_user_id',          false, false),
        ('approve_user_id',        false, true),
        ('approve_date_time',      false, true),
        ('flag',                   true,  true),
        ('type',                   true,  false),
        ('hospital_no',            true,  false),
        ('dept_code',              false, false),
        ('director_approval_id',   false, false),
        ('director_approval_time', false, false),
        ('apply_reason',           false, false)
),
actual AS (
    SELECT
        column_name,
        want_select,
        want_update,
        has_column_privilege(
            'mrzk_timeliness_write',
            'jhemr.jhmr_monitor_limit_log',
            column_name,
            'SELECT'
        ) AS actual_select,
        has_column_privilege(
            'mrzk_timeliness_write',
            'jhemr.jhmr_monitor_limit_log',
            column_name,
            'UPDATE'
        ) AS actual_update
    FROM expected
)
SELECT
    column_name,
    want_select,
    actual_select,
    want_update,
    actual_update,
    (want_select = actual_select AND want_update = actual_update) AS ok
FROM actual
ORDER BY column_name;
```

验收：14 行全部 `ok=true`。该矩阵同时检查权限缺失和整表 UPDATE 授权过宽，不得只查需要的列而忽略额外权限。
